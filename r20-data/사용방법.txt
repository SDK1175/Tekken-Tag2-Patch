태그2 통합 R19 — 시작 화면 진입 및 온라인 표시 선택

R18 및 이전 기능을 모두 포함한 누적 업데이트입니다. 이전 패치를 순서대로 설치할 필요가 없습니다.

• 로고·오프닝 건너뛰기: Press Start 화면으로 바로 진입합니다. Start는 직접 눌러 주세요.
• 온라인 커스터마이즈 투기 효과 복원: 사용자별 ON/OFF 선택이 가능합니다.
• 온라인 콤보 타수·대미지·카운터 표시: 사용자별 ON/OFF 선택이 가능합니다.
투기와 콤보 표시는 각각 켠 사람의 화면에만 자기·상대 양쪽이 표시됩니다. 한쪽만 켜면 그 사람만 보고, 양쪽 모두 켜면 각자의 화면에 표시됩니다. 두 기능은 독립적으로 선택하며 상대방 설정을 바꾸지 않습니다.

기존 R18 기능, 프랙티스 위치 저장·불러오기, 2P 카메라 수정, 프레임표 및 실행기 개선을 포함합니다. 기존 사용자별 패치 ON/OFF 설정을 보존합니다.

처음 패치하는 사용자 / 수동 설치
1. 게임과 RPCS3를 완전히 종료합니다.
2. Tag2_Integrated_R19.zip을 받아 압축 안의 파일과 폴더를 기존 rpcs3.exe가 있는 폴더에 덮어씁니다. R18 등 이전 패치는 따로 설치하지 않아도 됩니다. 게임 파일·펌웨어는 포함하지 않습니다.
3. patch.yml은 반드시 rpcs3.exe 옆의 patches 폴더에 넣습니다. 최종 경로는 RPCS3폴더\patches\patch.yml입니다. 압축에는 이 폴더 구조가 이미 포함되어 있습니다.
4. 기존 config\patch_config.yml을 삭제하거나 다른 사람의 파일로 덮어쓰지 마세요. 개인별 체크 설정이 저장된 파일입니다.
5. RPCS3의 게임 패치 관리에서 원하는 항목을 선택하고 저장합니다. 기존 체크 상태 보존을 위해 다음 이름을 그대로 유지했습니다.
   - 로고·오프닝 건너뛰기 - Press Start (시험판 1)
   - 온라인 커스터마이즈 투기 표시 (로컬 선택·시험판 1)
   - 온라인 콤보 타수·대미지 표시
   투기·콤보 표시는 기본 OFF이며 필요할 때 각각 켜세요. 적용·해제 후 게임과 RPCS3를 완전히 종료하고 다시 실행합니다.
6. 프레임표를 처음 사용하는 경우 실행기의 프레임표 설치 기능을 이용합니다.
파일 사용 중 오류가 나면 PC를 재부팅한 뒤 RPCS3 실행 전에 설치해 주세요.

기존 사용자 / 자동 업데이트
실행기에서 업데이트가 안내되면 설치를 선택합니다. 자동 업데이트에도 같은 최신 patch.yml이 내장되어 patches 폴더에 적용됩니다. R14 이하 사용자는 수동 설치를 권장합니다.
Tag2_Integrated_R19_auto.zip은 자동 업데이트용이며 수동 설치에는 Tag2_Integrated_R19.zip을 사용하세요.

실게임 확인: 세 패치의 정상 동작은 사용자 확인 내용을 반영했습니다. 이번 배포 준비에서는 추가 실게임 확인을 수행하지 않았습니다.
